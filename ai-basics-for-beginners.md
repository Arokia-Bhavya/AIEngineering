# AI Basics for Beginners — Notes

## Clean Mindmap (Text)

- AI
  - Machine Learning (ML)
    - Statistical ML
      - Supervised learning
        - Classification (binary, multiclass)
        - Regression (continuous value prediction)
      - Unsupervised learning
        - Clustering
        - Outlier detection
      - Common algorithms
        - Linear Regression, Decision Tree, Random Forest, XGBoost
        - K-means, DBSCAN, Hierarchical clustering
      - Tooling
        - Python, Pandas, NumPy, Matplotlib, Seaborn
        - Jupyter, scikit-learn, XGBoost
    - Deep Learning (DL)
      - Neural networks
      - Works better on unstructured data (image, text, audio, video)
      - Architectures: CNN, RNN, Transformer
      - Frameworks: PyTorch, TensorFlow
      - Compute: GPUs
  - Generative AI
    - Creates new content (text, image, audio, video)
    - Model examples
      - Text: GPT, Gemini, Claude, Llama
      - Image: DALL-E, Stable Diffusion
      - Video: Sora
  - Traditional AI vs GenAI
    - Traditional AI: analyze/predict/classify (structured outputs)
    - GenAI: generate novel content (unstructured outputs)
  - LLMs
    - Core engine behind modern GenAI
    - Intuition: next-token prediction at scale
  - AI Agents / Agentic AI
    - Workflow stage
      - RAG chatbot (reactive Q&A)
      - Tool-augmented chatbot (API/tool calls)
    - Agentic stage
      - Goal-based planning
      - Multi-step reasoning
      - Tool use + memory + autonomy
      - Executes actions, not just answers
    - Distinction
      - AI agent: one acting unit
      - Agentic AI: system with one or more agents

## Key Takeaways

1. AI is the umbrella; ML and DL are subdomains inside it.
2. Statistical ML is strong on structured/tabular data.
3. Deep learning dominates unstructured data use cases.
4. GenAI produces content; traditional AI mostly predicts/classifies.
5. LLMs power current GenAI systems.
6. Agentic AI adds planning, tool use, and autonomous execution.
